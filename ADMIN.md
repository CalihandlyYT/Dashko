# Администратор сайта

Права администратора дают доступ к странице **Админ-панель** (`/admin.html`): список пользователей, отзывов и удаление отзывов.

## Как назначить администратора

1. Установите переменную окружения **`ADMIN_EMAIL`** (или `DASHKO_ADMIN_EMAIL`) в **нижнем регистре**, совпадающую с email учётной записи в системе.

2. Запустите сервер и **войдите** под этим email (или зарегистрируйте такой аккаунт).

3. После входа в шапке появятся ссылки **«Админ»** и в профиле — пометка администратора.

### Windows (PowerShell)

```powershell
$env:ADMIN_EMAIL="ваш@email.com"
cd c:\Dev\dashko
python main.py
```

### Linux / macOS

```bash
export ADMIN_EMAIL="ваш@email.com"
python main.py
```

Если переменная не задана, у всех пользователей `is_admin = 0`, админ-панель недоступна.

## Безопасность

- Админ-панель и API `/api/admin/*` работают только при **локальном** запуске `python main.py`.
- На **GitHub Pages** бэкенда нет — вход и админка там не функционируют.
